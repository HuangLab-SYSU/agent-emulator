# RWA 算力交易实验图册洞察

本文档总结扩展版 RWA 算力交易实验图册中的主要观察结论。图册来自 `../../figs/archived_results/figs_results-rwa-20261009-1350/index.html`，包含 16 张图，覆盖 Agent 余额变化、RWA 算力成交规模、价格数量关系、买卖网络关系和 Agent 净交易角色等视角。

## 实验概况

本轮实验将 RWA 算力交易场景扩展为更多 Agent、更多算力类型和更丰富的价格/数量组合。

- Agent 数量：12 个，`agent-001` 到 `agent-012`。
- 算力类型：6 类，分别为 `gpu-a100-hour`、`gpu-h100-hour`、`cpu-epyc-core-hour`、`cpu-xeon-core-hour`、`tpu-v4-hour`、`fpga-vu9p-hour`。
- Trace 记录：48 条，包括 12 条 `join`、12 条 `sell`、24 条 `buy`。
- 链上 RWA 汇总结果：`rwa_orders.csv` 中包含 22 条 `sell` 记录和 44 条 `buy` 记录。
- 本轮没有余额不足买入交易，`insufficient_balance_count` 均为 0。

## 核心洞察

### 1. 市场规模主要由成交数量驱动，而不是单价最高的算力驱动

从 RWA 汇总数据看，`tpu-v4-hour` 的成交单价最高，均价约为 `1,185,000`，但总成交额只有 `33,040,000`。相反，`cpu-epyc-core-hour` 单价较低，均价约为 `89,000`，但由于总购买数量达到 `1170`，总成交额达到 `104,000,000`，是本轮最高。

这说明当前实验中，成交额更受 `quantity` 驱动，而不是单纯由 `unit_price` 决定。低单价、高成交量的算力可以贡献更大的市场规模。

### 2. CPU 类算力在成交额上超过 GPU/TPU 类高价算力

按总成交额排序如下：

```text
cpu-epyc-core-hour     104,000,000
cpu-xeon-core-hour      66,880,000
gpu-a100-hour           59,630,000
fpga-vu9p-hour          48,060,000
gpu-h100-hour           43,160,000
tpu-v4-hour             33,040,000
```

这表明 CPU 类算力在当前实验设定下更像大宗基础资源，成交份数大、市场容量高；GPU、TPU 和 FPGA 更像高价或稀缺资源，单价较高但成交规模受数量约束。

### 3. Agent 虽然都可以既买又卖，但最终形成净买方和净卖方分化

`RWA 各 Agent 净交易额` 图显示，即使每个 Agent 都可以同时参与买入和卖出，实验结束后仍然出现明显角色分化。

净收入最高的 Agent：

```text
agent-006    +42,840,000
agent-010    +29,840,000
agent-005    +20,980,000
agent-001    +10,630,000
```

净支出最高的 Agent：

```text
agent-008    -25,360,000
agent-011    -24,210,000
agent-002    -20,010,000
agent-009    -14,350,000
agent-012    -13,360,000
```

这说明市场自然形成了资源净供给方和资源净消费方。`agent-006`、`agent-010`、`agent-005` 更偏向净供给方，`agent-008`、`agent-011`、`agent-002` 更偏向净消费方。

### 4. 买卖关系不是均匀分布，而是存在大额交易连接

`RWA 买方-卖方成交金额热力图` 显示，一些买卖方之间存在明显的大额连接。本轮排名靠前的买卖关系包括：

```text
agent-008 -> agent-005    34,000,000
agent-009 -> agent-010    32,200,000
agent-011 -> agent-006    31,920,000
agent-012 -> agent-010    27,600,000
agent-010 -> agent-006    21,280,000
```

这说明 RWA 市场中并非所有 Agent 均匀交易，而是出现了若干关键供给节点和高额消费连接。`agent-006`、`agent-010`、`agent-005` 是本轮比较重要的供给侧节点。

### 5. 价格-数量散点图与数量-金额气泡图共同揭示算力资源定位

`RWA 价格-数量散点图` 从单笔交易角度展示不同价格下的购买数量，适合观察单笔成交是否存在高价大额、低价小额等模式。

`RWA 算力数量-金额气泡图` 从算力资源汇总角度展示每类算力的总成交数量、总成交金额和交易规模，适合比较不同算力资源的整体市场表现。

结合两张图，可以区分不同资源的市场定位：

- `cpu-epyc-core-hour`：低单价、高数量、大市场规模。
- `cpu-xeon-core-hour`：低单价、高数量，成交额排名靠前。
- `gpu-a100-hour`：价格和数量处于中间区间，成交额也较靠前。
- `fpga-vu9p-hour`：单价中高、数量中等，成交额居中。
- `gpu-h100-hour`：高单价、较低数量，成交额受成交数量限制。
- `tpu-v4-hour`：最高单价、最低数量，属于高价稀缺型资源。

### 6. 余额类图验证链上资金守恒，同时展示 Agent 个体差异

图 1 到图 4 主要展示 Agent 余额变化。由于 `buy` 交易是买方向卖方付款，系统内部资金转移应整体守恒，因此全局平均或整体净变化最终接近 0。

但单个 Agent 的余额变化差异明显：净卖方余额上升，净买方余额下降。图 2 更适合观察全局交易顺序下的资金流动，图 3 更适合观察每个 Agent 在自身交易生命周期中的归一化趋势，图 4 更适合查看分组 Agent 的个体轨迹。

需要注意，`sell` 在当前实现中是挂牌/记录型交易，不产生真实转账；真正改变余额的是 `buy` 交易。

### 7. 当前实验适合分析市场结构，不适合分析余额不足异常

本轮所有算力的 `insufficient_balance_count` 均为 0，因此余额不足交易没有形成有效图形信息。当前图册更适合分析：

- 市场结构。
- 算力资源成交规模。
- 价格与数量关系。
- 买方与卖方交易网络。
- Agent 净交易角色分化。

如果后续需要研究“余额不足但保留链上记录”的异常场景，可以专门设计超大额 `buy` 交易，让余额不足交易在 CSV 和图表中产生可观察信号。

## 最有价值的图表

本轮 16 张图中，最值得重点关注的图包括：

- `RWA 各算力资源成交金额`：判断哪类算力贡献主要市场规模。
- `RWA 按成交额的算力市场份额`：快速观察市场份额结构。
- `RWA 买方-卖方成交金额热力图`：识别关键买卖连接和核心供给方。
- `RWA 各 Agent 净交易额`：识别净供给方和净消费方。
- `RWA 价格-数量散点图`：观察单笔交易的价格与数量关系。
- `RWA 算力数量-金额气泡图`：比较各类算力资源的整体市场表现。

## 总结

当前 16 张图已经能够支撑一个较完整的 RWA 算力交易市场分析故事：低单价、高数量的 CPU 算力贡献了最大的成交规模；GPU、TPU 和 FPGA 更偏向高价或稀缺资源；虽然 Agent 都可买可卖，但市场最终分化出明显的净买方、净卖方和少数核心交易连接。

这说明扩展后的实验不仅能够验证 RWA 交易能被链上记录和后处理汇总，也能够支持进一步分析算力市场中的资源定位、交易网络结构和 Agent 行为差异。
