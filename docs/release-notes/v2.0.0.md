# AgentEmulator v2.0.0

The second release of AgentEmulator, an emulation and experimentation platform for trustworthy AI agent infrastructure built by [HuangLab](http://www.xintelligence.pro/) (Sun Yat-sen University) on top of [BlockEmulator-X](https://github.com/HuangLab-SYSU/block-emulator-x). On top of the v1.0 Agent behavior replay mode, v2.0 adds **LLM API integration mode**: one identity from the Trace file is handed to a model API for online control, while all other identities still act as described in the Trace file.

## Highlights

- **LLM API integration mode.** Pick an identity with a `join` record in the Trace file as the API Agent. Each decision round, the on-chain supervisor collects snapshots from all shards (confirmed balances, available balance net of pending spends, shard heights, latest block digests) and hands them to AgentSupervisor, which calls the external model API, parses the reply (`pay` / `wait` / `leave`), validates the decision against fresh on-chain state, and submits the accepted ones as on-chain transactions. Works with DeepSeek and Qwen (DashScope) out of the box; any OpenAI-compatible endpoint fits the `chat-completions` adapter. This mode supports only the `static_relay` consensus.
- **LLM API calls run in the experiment process.** LLM API calls are issued by `agentSupervisor` (the parent process), which exposes a loopback decision endpoint to the on-chain supervisor per run. Keys are read from a local file or an environment variable every round, and never enter traces, chain configs, or logs.
- **Global block quota during reasoning.** While the model reasons, `agent_api.max_blocks_during_decision` caps the block quota shared by all shards (empty and in-flight proposals also consume the quota), so a slow model call cannot flood the chain — and its effect on background-transaction confirmation becomes measurable.
- **Decision observability.** `agent_thinking.log` records `thinking_started` / `thinking_finished` / `decision_result` per decision round, linked by a `decision` number; `hybrid_summary.json` keeps every round's observation, the raw provider reply (model name, response ID, token usage), timing, and the final snapshot. Summaries are single-line and length-capped.
- **Timeline and cross-model comparison figures.** `figs/python_code/agent_timeline.py` renders a run as a relative-time chart (balance staircase, price thresholds, purchase arrows) plus event tracks for snapshot collection, model reasoning, decision proposal, and Trace injection, with a cumulative-block-count variant. The balance curves of two models can also be compared side by side.
- **Trace hardening in LLM API integration mode.** Invalid background Trace actions (inactive counterparty, duplicate `leave`, zero-amount pay) are skipped before compilation and appended to `round_001/trace_failures.jsonl` with the Trace line number, planned action, and reason; the run continues. Hard errors (malformed Trace files, plain transfers spending directly from the API Agent's account) still abort the experiment.
- **New bundled scenario.** `traces/metals_savings_22000.jsonl` is the new default demo (the metals scenario): 22,000 background payments plus staged funding and a gold/silver supplier switch. The API Agent starts at 15, buys gold at 160 while the gold supplier is online, switches to silver at 100 while it is offline, and returns to gold after it re-joins. `traces/wait_for_funds.jsonl` provides a minimal "wait until funded" check. Generators and offline unit tests live in `scripts/`.

## Changes since v1.0.0

- **License changed to PolyForm Noncommercial 1.0.0.** v1.0.0 shipped under MIT; use, distribution, and changes are now limited to noncommercial purposes.
- **The default configuration now starts LLM API integration mode** (`agent_api.enabled: true`, `agent_id: agent-metal-buyer`, the metals scenario). Set `agent_api.enabled: false` to switch back to Agent behavior replay mode, and additionally `chain.enabled: false` for compile-only preview.
- **Demo Trace set refreshed.** `minimal.jsonl` and `agent=100_txs=10000.jsonl` remain; earlier online-decision samples were removed in favor of the metals and wait-for-funds traces.
- **`chain.run_timeout_seconds` now bounds the whole single-chain run** (startup + active phase + drain) when `agent_api.enabled: true`; in this mode `loop.max_rounds` is ignored.

## Quick start

Requires Go ≥ 1.25.7, Python 3 with `matplotlib` / `numpy` / `pandas` (ImageMagick optional, for standalone timeline exports), and an LLM API Key for a Chat Completions-compatible service.

```bash
git clone https://github.com/HuangLab-SYSU/agent-emulator.git
cd agent-emulator
go build ./...
mkdir -p .secrets
printf 'YOUR_DEEPSEEK_API_KEY' > .secrets/deepseek_api_key   # key only, no quotes
go run ./cmd/agentemu -config agentEmuConfig.yaml
```

The run executes the metals scenario with the API Agent `agent-metal-buyer` (active phase 600 s), writes ledgers and decision logs under `exp/metals-savings-22000-deepseek/`, and — via `run_agentemu.sh` (Windows: `run_agentemu.bat`) — regenerates the balance figures and opens the HTML gallery. See [README.md](https://github.com/HuangLab-SYSU/agent-emulator/blob/main/README.md) for LLM API configuration, result verification, and troubleshooting.

## Distribution

This is a source-only release — no prebuilt binaries are shipped. Clone the repository and run from source as shown in Quick start: the `agentemu` entry point compiles the chain binaries at start-up, which requires a local Go toolchain (≥ 1.25.7).

# AgentEmulator v2.0.0（中文说明）

AgentEmulator 的第二个版本。AgentEmulator 是由中山大学 [HuangLab](http://www.xintelligence.pro/) 基于区块链仿真平台 [BlockEmulator-X](https://github.com/HuangLab-SYSU/block-emulator-x) 构建的可信 AI Agent 基础设施仿真与实验平台。v2.0 在 Agent 行为回放模式的基础上新增 **LLM API 接入模式**：把 Trace 文件中的一个身份交给模型 API 在线控制，其余身份仍按 Trace 文件中的预设行为行动。

## 版本要点

- **LLM API 接入模式。** 从 Trace 中选出一个有 `join` 记录的身份作为 API Agent。每轮决策包含观察、推理和执行决策三个步骤：链上 Supervisor 从各分片收集快照（已确认余额、扣除待确认支出后的可用余额、分片高度、最新区块摘要），交给 AgentSupervisor 调用外部模型 API，解析大模型回复（`pay` / `wait` / `leave`），校验通过后把付款提交上链。DeepSeek 和通义千问（DashScope）开箱即用；任何 OpenAI 兼容接口都能接入 `chat-completions` 适配器。该模式仅支持 `static_relay` 共识。
- **大模型调用在实验主进程执行。** 大模型调用由外层 agentSupervisor 进程发起，每次运行通过本机回环决策接口与链上 Supervisor 通信。密钥每轮从本地文件或环境变量读取，不进入 Trace、链配置和日志。
- **思考期间的全局出块配额。** 大模型思考期间，`agent_api.max_blocks_during_decision` 限制所有分片共享的出块配额，空块和共识中的提议都计入额度；额度耗尽后 Supervisor 暂停发放新的出块许可。这样，慢的大模型调用不会让链上持续出块，其对背景交易确认的拖延也变得可测量。
- **决策可观测。** `agent_thinking.log` 按决策轮记录 `thinking_started` / `thinking_finished` / `decision_result`，用 `decision` 编号关联每轮的观察、大模型回复和校验结果；`hybrid_summary.json` 保存每轮观察、服务商原始回复（模型名、响应 ID、Token 用量）、耗时和最终快照。摘要压成单行并限制长度。
- **时间线图与多模型对比图。** `figs/python_code/agent_timeline.py` 把一次运行画成相对时间图（余额阶梯、价格门槛、购买箭头）加四条事件轨道（快照采集、大模型思考、决策产生、动作注入），另有按累计区块数的变体；两个大模型的余额曲线可以并排对比。
- **LLM API 接入模式下的 Trace 加固。** 无效背景 Trace 动作（收款方不活跃、重复 `leave`、金额为零的付款）在编译前被跳过，连同行号、计划动作和原因追加到 `round_001/trace_failures.jsonl`，实验继续。硬错误（Trace 文件格式错误、普通转账试图直接从 API Agent 的账户支出）仍然终止实验。
- **新的自带场景。** `traces/metals_savings_22000.jsonl` 贵金属场景是新的默认演示：22,000 笔背景支付，外加分批拨款和黄金供应商上下线。API Agent 初始余额 15，黄金供应商在线时按 160 买黄金，下线期间按 100 买白银，重新上线后恢复买黄金。`traces/wait_for_funds.jsonl` 提供“等待入账再付款”的最小验证。生成脚本和离线单元测试在 `scripts/`。

## 相对 v1.0.0 的变化

- **许可证改为 PolyForm Noncommercial 1.0.0。** v1.0.0 采用 MIT；现在使用、分发和修改仅限非商业目的。
- **默认配置启用 LLM API 接入模式**（`agent_api.enabled: true`，`agent_id: agent-metal-buyer`，贵金属场景）。设 `agent_api.enabled: false` 回到 Agent 行为回放模式；再设 `chain.enabled: false` 可只做编译预览。
- **演示 Trace 更新。** 保留 `minimal.jsonl` 和 `agent=100_txs=10000.jsonl`；此前的在线决策样例 Trace 已移除，换成贵金属和等待入账两个 trace。
- **`chain.run_timeout_seconds` 在 `agent_api.enabled: true` 时约束整场单链运行**（启动 + 活跃期 + 收尾）；该模式下 `loop.max_rounds` 不生效。

## 快速开始

需要 Go ≥ 1.25.7、Python 3（含 `matplotlib` / `numpy` / `pandas`；单独导出时间线图还需 ImageMagick），以及一个兼容 Chat Completions 的 LLM API Key。

```bash
git clone https://github.com/HuangLab-SYSU/agent-emulator.git
cd agent-emulator
go build ./...
mkdir -p .secrets
printf 'YOUR_DEEPSEEK_API_KEY' > .secrets/deepseek_api_key   # 只放 Key 本身，不加引号
go run ./cmd/agentemu -config agentEmuConfig.yaml
```

运行贵金属场景，买家 `agent-metal-buyer` 由 LLM API 控制（活跃期 600 秒），在 `exp/metals-savings-22000-deepseek/` 下输出账本和决策日志；用 `run_agentemu.sh`（Windows 为 `run_agentemu.bat`）启动还会重新生成余额图表并打开 HTML gallery。LLM API 接入配置、结果核对和排查见 [README_zh.md](https://github.com/HuangLab-SYSU/agent-emulator/blob/main/README_zh.md)。

## 分发方式

本 release 仅提供源码，不附带预构建二进制。请按“快速开始”克隆仓库并从源码运行：`agentemu` 入口会在启动时编译链上二进制，因此需要本地 Go 工具链（≥ 1.25.7）。
